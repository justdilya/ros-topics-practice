# Топик: Лидар и TF (Transform) в ROS

## Цели топика:
- Изучить работу с лидаром в ROS
- Понять систему TF (трансформаций)
- Научиться настраивать Rviz для отображения данных лидара
- Освоить инструменты для работы с TF

## Launch-файлы:

### 1. turtlebot3_sim_start.launch
- Запуск симуляции Gazebo
- Публикация TF из модели робота
- Запуск Rviz

### 2. turtlebot3_tf.launch
- Статический TF между base_footprint и base_scan

### 3. turtlebot3_lidar_demo.launch
- Полная демонстрация: симуляция + TF + Rviz

## Ключевые понятия:
- **TF (Transform)**: система координатных преобразований
- **Статический TF**: преобразования, не меняющиеся во времени
- **Динамический TF**: преобразования, меняющиеся во времени
- **Фрейм (Frame)**: система координат

## Инструменты:
- `rqt_tf_tree` - визуализация дерева TF
- `tf_echo` - просмотр численных значений TF
- `static_transform_publisher` - публикация статических TF
